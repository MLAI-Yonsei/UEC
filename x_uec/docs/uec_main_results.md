UEC main의 원본 전처리 함수를 직접 실행해 seed 2025의 MS MARCO 3,983쌍/SNLI 3,775쌍과 문장 순서가 모두 일치함을 확인했습니다. 이전 로컬 선택과는 다른 자료이며 이번 결과를 별도로 기록합니다.

공개 모델·데이터 캐시만 공유하고 이전 실험 모듈의 import를 차단한 별도 소스 폴더에서 실행했습니다. 공개 GitHub를 다시 clone한 코드의 32개 실행 소스 해시도 이 전체 실행과 일치합니다.

GTE는 최초32회에서 좌표1개의 MC 정밀도 검산이 미달해, seed와 허용식을 유지한64회로 재계산했습니다. 최대 절대 z는3.39676에서2.55904로 낮아졌고 검산을 통과했습니다. 원래32회의 난수·좌표값과 같은 정확 목표값을 유지했음을 대조했습니다. 실패 기록과 실제 추가 실행 소스도 보관했습니다.

## 불확실성 피팅의 분산 변화

| 모델 | 실제 곡률 추정 횟수 | prior 대비 파라미터 분산의 평균 감소율 |
|---|---:|---:|
| qwen | 32 | 0.555389% |
| harrier | 32 | 5.81807% |
| gte | 64 | 0.00401825% |

이는 원본 인코더를 고정한 상태에서 마지막 projection 가중치의 Gaussian 분산을 비교한 값입니다. 대부분의 좌표에서는 prior의 영향이 크며, 특히 GTE의 평균 감소율이 작습니다. 문장별 출력 분산의 감소율이나 불확실성 보정 성능을 뜻하는 값은 아닙니다. 실제 배열에서 variance_teacher=1/(prior_precision+GGN_diagonal)도 재검산해 통과했습니다.

## 해석 범위

진단은 같은 UEC 선택 자료 안에서 정렬에 사용하지 않은 문장 그룹으로 수행했습니다. 불확실성 피팅에는 진단 관측도 포함되므로 **정렬에 대해서만 보류한 자료**이며 `posterior_unseen=false`입니다.
과거 외부 평가 6과제의 해시와 겹치는 관측 20개는 참고로 보고했으며 main 기본 선택을 바꾸지 않았습니다. 별도 외부 평가를 진행할 때는 그 평가 범위를 정하고 중복을 제외해야 합니다.
이 페이지는 정렬 목적함수·수렴·공분산 계산에 대한 검증입니다. 추가한 원본·변환 후·균등 결합의 실제6태스크 성능 비교는 [성능 결과](performance.md)에 별도로 기록했습니다. 원래 UEC-LA와 같은 posterior, 불확실성 가중 UEC 최종 점수와 전체 MMTEB 성능을 검증한 결과는 아닙니다.
