# UEC main 선택 데이터의 CAIA v3 전체 실행

[실행 안내](../README.md) · [선택 코드와 입력](data.md) · [이전 로컬 선택 결과](results.md)

현재 전체 계산을 진행하고 있습니다. 이 페이지에는 완료 후 새 실행의 실제 결과를 기록합니다. 이전 로컬 선택 결과를 이번 실행의 결과로 사용하지 않습니다.

UEC main 원본 전처리 함수를 직접 실행해 seed 2025의 MS MARCO 3,983쌍/SNLI 3,775쌍과 문장 순서가 모두 일치함을 확인했습니다. 기본 main 선택 7,758쌍을 모두 유지하고, 총 15,516개 문장 관측을 12,414개 정렬용/3,102개 진단용으로 나눕니다. 같은 문장 그룹은 양쪽에 겹치지 않습니다.

불확실성은 이 자료에서 원본 인코더를 고정하기 위해 채택한 frozen-teacher 곡률 근사로 새로 피팅합니다. 진단 관측도 불확실성 피팅에는 포함되므로 정렬에 대해서만 보류한 진단입니다. UEC 최종 점수나 별도 검색·분류·STS 성능 평가는 포함하지 않습니다.
