# 실제 성능 평가: 원본 모델과 균등 결합

2026-11-27 검증 실행은 11조건 × 8과제, 총 88개 점수 행을 92.76초에 계산했습니다. 아래 외부 결과는 **중복을 제거한 6과제 pilot**이며 전체 MMTEB 결과가 아닙니다.

점수는 검색 NDCG@10, 분류 accuracy, STS Spearman에 각각 100을 곱한 값입니다. 분류는 원래의 support 추출 10회를 그대로 사용한 평균입니다. Q/H/G는 Qwen/Harrier/GTE입니다.

균등 결합은 각 모델에 고정된 정렬 맵 R을 적용하고, 세 임베딩을 각각 1/3 가중치로 평균한 뒤 L2 정규화하여 cosine으로 평가합니다. 불확실성 가중 UEC 최종 점수는 이 평가에 포함되지 않습니다. 모든 11조건은 동일한 캐시 평균, 평가 항목·정답·support 및 동결된 인코더 가중치를 사용합니다.

피팅에 사용한 전체 7,758개 쌍의 양 끝점(고유 해시 15,367개)과 평가 텍스트를 대조했습니다. STSBenchmark에서 겹친 텍스트 19개와 해당 쌍 19개를 제외하여 1,379쌍 → 1,360쌍으로 평가했습니다. 나머지 5과제는 제외 항목이 없습니다. NFC와 줄바꿈만 정규화하여 비교했습니다.

총 36개 단독 모델 비교에서 실제 저장 점수가 정확히 같았습니다. 전체 비교 cosine의 최대 절대 오차는 2.220e-15, 원본 분류 head를 함께 운반한 logit의 최대 절대 오차는 2.442e-15로, 모두 1e-8 이하입니다. 분류 본 점수는 같은 설정의 LogisticRegression(random_state=42, n_jobs=1, max_iter=100)을 재피팅한 결과이며, 운반 검증은 별도로 기록했습니다.

균등 GPA → CAIA의 변화는 과제별로 작고 방향이 섞여 있습니다. 통계적 유의성 검정을 수행하지 않았으므로 성능 향상이나 일반적 우월성을 주장하지 않습니다. 표만 소수점 6자리로 표시했으며, 첨부 CSV/JSON은 실제 float 값을 보존합니다.

내부 결과는 같은 불확실성 피팅 자료에서 정렬만 홀드아웃한 positive-pair matching입니다. posterior에는 이미 사용된 자료이며, SNLI 분류나 STS 벤치마크 점수로 해석할 수 없습니다.

외부 평가의 원본 캐시는 현재 피팅 런타임과 비트 단위로 동일하지 않습니다. 특히 Qwen 캐시는 flash_attention_2 및 FP16 출력 정규화를 사용했고, 현재 피팅은 SDPA 및 FP64로 재구성한 최종 특징 경로를 사용했습니다. 이 차이와 원래 과제별 프롬프트를 유지한 상태에서, 평가 조건끼리는 동일한 캐시 평균을 공유했습니다.
